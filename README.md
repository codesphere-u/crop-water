# crop-water

**Zero-dependency FAO-56 Penman-Monteith reference evapotranspiration (`ET₀`), daily root-zone soil-water balance, and solar-pump drip irrigation scheduler for climate-resilient smallholders.**

Pure Python 3.11+. Computes exact daily reference evapotranspiration (`mm/day`), water-stress coefficients (`Ks`), effective rainfall infiltration, gross irrigation volumes (`m³`), and hydraulic solar-pumping energy (`kWh`).

## Quick Start

```bash
uv sync --extra dev
crop-water demo
```
